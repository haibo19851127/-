// whoami — 这个博客是做什么的

你好，我是这个博客的作者。这里是我的工程笔记本：记录日常开发中的技术决策、踩坑过程与复盘思考，也保留一些与代码无关的个人想法。

我关注什么

偏好简单、可维护、少依赖的技术方案——能用原生技术解决的问题，不引入额外框架；能静态部署的站点，不搭建服务器。视觉上喜欢工程制图般的线框与几何感，所以你看到了现在这个 3D 背景。

// 技术栈

HTML / CSS / 原生 JavaScript、Three.js、静态站点与前端工程化实践。

// 写作主题

前端实现笔记、部署与运维记录、工具链选型、设计与工程的交叉思考。

// 更新频率

不追求固定周期；有值得记录的实践或结论时更新，优先保证内容密度。
